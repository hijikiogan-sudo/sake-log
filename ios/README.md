# 缶ログ iOS（検証用）

`beer-save/` のWeb版を、そのままiPhoneアプリとして動かすためのXcodeプロジェクトです。
Web版のファイルは複製せず `../beer-save` を参照しているので、Web版を直せばアプリにも反映されます。

## 必要なもの
- Mac と Xcode（15以降）
- Apple ID（無料でも可。無料の場合、実機に入れたアプリは7日で起動できなくなるので入れ直します）
- iPhone（iOS 16以降）とケーブル

## iPhoneで動かす手順
1. このリポジトリを取得して `claude/canned-alcohol-app-review-jo7w7y` ブランチに切り替える
2. `ios/KanLog.xcodeproj` をダブルクリックしてXcodeで開く
3. 左の一覧で一番上の **KanLog** → TARGETS の **KanLog** → **Signing & Capabilities** を開く
   - **Team**：自分のApple IDを選ぶ（なければ「Add an Account…」で追加）
   - **Bundle Identifier**：`com.example.kanlog` を自分だけの名前に変える（例：`com.hijikiogan.kanlog`）
4. iPhoneをMacにつなぎ、Xcode上部の実行先で自分のiPhoneを選ぶ
5. ▶（Run）を押す

初回だけ、iPhone側で次の設定が必要です。
- **デベロッパモード**：設定 → プライバシーとセキュリティ → デベロッパモード をオンにして再起動
- **開発元の信頼**（無料のApple IDの場合）：設定 → 一般 → VPNとデバイス管理 → 自分のApple ID → 信頼

## アプリ側で補っていること
| Web版の機能 | アプリでの動き |
|---|---|
| JSON / CSV の保存 | 共有シートが開き、「"ファイル"に保存」などを選べる |
| 確認ダイアログ | iOSの標準ダイアログで表示 |
| バーコード読み取り | 初回にカメラの許可を求める |
| 外部リンク（厚生労働省） | Safariで開く |
| アプリの更新 | 表示しない（App Storeで更新するため） |

記録はアプリ内に保存され、Safariで使っているWeb版の記録とは別になります。
Web版の記録を移すときは、Web版で「JSONを保存」→ アプリの設定で「バックアップから読み込む」。

## 確認してほしいこと
- 起動・記録・履歴・集計が動くか、画面上下の余白（ノッチ・ホームバー）が自然か
- アプリを終了して起動し直しても記録が残っているか
- バーコード読み取り（カメラ）、写真から読み取り
- 設定 → JSONを保存 / CSVを保存 で共有シートが開き、ファイルに保存できるか
- バックアップから読み込む（ファイル選択）

## 不具合を調べるとき
Debugビルドでは、Mac の Safari → 開発 → （iPhone名）→ 缶ログ でWeb版と同じように調べられます。
